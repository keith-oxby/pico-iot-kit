# Security policy

## Reporting a vulnerability

Please report security problems privately, using GitHub's
["Report a vulnerability"](../../security/advisories/new) form on this
repository's Security tab, rather than opening a public issue.

## Scope

The security model, including what is deliberately deferred (encrypted-at-rest
secrets, OTA updates) and the documented public default setup-AP password, is
described in [docs/security.md](docs/security.md). Reports that only restate a
documented limitation are welcome as suggestions but are not vulnerabilities.
